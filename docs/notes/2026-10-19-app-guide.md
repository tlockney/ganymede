## 2026-10-19, app guide and where things run (#177)

Step 3 of the docs review: the pages that described the Mac and iPad app
as a plan now describe what was built.

- New guide, `app.md` ("Ganymede's app"): the three ways to run
  ganymede-ui (`ganymede ui`, the Mac and iPad app, the browser alone),
  where notebooks and kernels live in each, getting the Mac build from
  CI, kernel servers, and the toolbar, shortcuts and trust. The
  `ganymede ui` section moved here from `frontends.md`.
- New diagram, `where-kernels-run.svg`, used on Architecture, the app
  guide and the iPad page.
- Architecture: "Deployment profiles" (a table of a design that wasn't
  built: in-app bridge, embedded kernelspec list, no HTTP on the iPad)
  became "Where it runs". The seams table now has Built and Not built
  columns; the TypeScript rows went, since ganymede-ui uses JupyterLab's
  packages and documents its own seams.
- `ipados.md` rewritten from the original plan into what was built, what
  is left, and the decisions that came out of it. The plan's message
  bridge was dropped for the ordinary server on loopback inside the app.
- `ui.md`: the UI options are now the two that exist plus the native one
  that wasn't pursued.
