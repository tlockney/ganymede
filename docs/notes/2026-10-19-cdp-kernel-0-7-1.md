## 2026-10-19, cdp-kernel 0.7.1 (#213)

- CI's `CDP_KERNEL_VERSION` and `container/Dockerfile`'s default move from
  0.6.0 to 0.7.1, so the first published container image carries the
  current kernel. Architecture's tested-versions table and Development
  name the same version.
- 0.7.1 adds `user_expressions`, the installed TypeScript version in
  `kernel_info_reply`, start timeouts for Bun, workerd and celld targets,
  and survives non-JSON runtime messages; the e2e suite runs against it
  on Linux and macOS.
