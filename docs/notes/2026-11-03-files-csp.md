## 2026-11-03, `/files` sandbox CSP (#298)

`GET /files/{path}` served `.html` and `.svg` as active content on the
server's own origin. A file in the notebook folder, opened from a
Markdown link or "Open in New Browser Tab", could then read the token in
session storage and the agent's keys in web storage. In the Mac and iPad
apps it also passed the `agentKeys` handler's origin check.

jupyter_server's `FilesHandler` appends `sandbox allow-scripts` to its
`Content-Security-Policy`, which gives the document an opaque origin:
scripts still run, but storage, cookies and same-origin fetches are
cut off. Ganymede sends the same directive on every `/files` response.
It does not send jupyter_server's base `frame-ancestors 'self'` and
`report-uri` parts, since Ganymede sets no CSP on other routes and has
no report endpoint.
