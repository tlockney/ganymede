## 2026-11-09, cdp-kernel 0.9.0 (#621)

CI, the container image and the docs now use cdp-kernel 0.9.0. It
brings cdp-kernel #444: a later cell can redeclare a name an earlier cell
declared another way (`import { x }` after `const x`), the clash that
broke the journal run's probe cells (#609). Top-level `const` now runs as
`let`, so a later cell can reassign it.
