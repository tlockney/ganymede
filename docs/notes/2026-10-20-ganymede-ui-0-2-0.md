## 2026-10-20, ganymede-ui 0.2.0 by default (#216)

- `ganymede ui install` installs ganymede-ui 0.2.0 unless `--version`
  says otherwise, checked against the zip's SHA-256 from the release's
  `SHA256SUMS` (pinned in `crates/ganymede-cli/src/ui.rs`).
- Release order follows from the pin: release ganymede-ui first, move the
  default here, then cut the ganymede release that ships it.
