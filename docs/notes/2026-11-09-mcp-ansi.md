## 2026-11-09, MCP replies without ANSI colours (#610)

A real ganymede-journal run on cdp-kernel showed results reaching the
agent as `\x1b[32m'day'\x1b[39m`: cdp-kernel's `text/plain` is Node's
`util.inspect` with colours on, and the MCP reply stripped escapes only
from tracebacks. `render_outputs` now strips them from every body it
sends (streams, Markdown, plain text, stripped HTML) before the inline
limit is applied, so a spilled file has none either. The notebook keeps
the colours, which JupyterLab and the apps render for people.
`render_outputs` and `spill` became free functions so a test can call
them without a server.

The same run hit a declaration clash: a scratch probe's
`const { hourly }` made a recorded `import { hourly }` fail. V8's REPL
mode only lets a name be redeclared with the same kind of declaration,
and cdp-kernel turns imports into `var`. The kernel fix is
tlockney/cdp-kernel#444; until it ships, the journal skill tells agents to
wrap TypeScript probes in a block.
