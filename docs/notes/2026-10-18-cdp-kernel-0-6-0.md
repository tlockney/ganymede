## 2026-10-18, cdp-kernel 0.6.0 pin (#132)

- CI's `CDP_KERNEL_VERSION` moves from 0.5.0 to 0.6.0; README and
  [workstation.md](../workstation.md) follow.
- 0.6.0 ships `cdp-kernel list` and `cdp-kernel uninstall`
  (cdp-kernel#249), so the workstation page's uninstall step uses
  `cdp-kernel uninstall cdp-node` in place of `ganymede kernelspec remove`,
  and `scripts/test-workstation.sh` runs both commands. It removes only
  kernelspecs cdp-kernel wrote, from the same kernels directory Ganymede
  reads, so the check that `ganymede kernelspec list` no longer shows
  `cdp-node` still holds.
