## 2026-11-09, ganymede-ui 0.6.0 by default (#601)

`ganymede ui install` now installs ganymede-ui 0.6.0. `DEFAULT_SHA256`
is the SHA-256 of `ganymede-ui-0.6.0.zip` from the release's
`SHA256SUMS`, checked against a download. The zip is about 4.8 MB (10 MB
unpacked), well inside the install limits.

The apps in 0.6.0 need macOS 26 or iOS 26, and the Mac app is Apple
silicon only, so the landing page and docs/app.md lose their
"Unreleased in ganymede-ui." markers and state the new floor. The server
and CLI keep their wider OS and Intel support.
