## 2026-11-06, ganymede-ui 0.5.0 by default (#420)

`ganymede ui install` now installs ganymede-ui 0.5.0 (the single Mac
Settings window, cdp-kernel 0.8.0 bundled). `DEFAULT_SHA256` is the
SHA-256 of `ganymede-ui-0.5.0.zip`, not the `.tar.gz`: the installer
downloads the zip, and both are listed in the release's `SHA256SUMS`.
