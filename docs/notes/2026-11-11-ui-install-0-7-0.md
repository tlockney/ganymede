## 2026-11-11, ui install pins ganymede-ui 0.7.0 (#672)

ganymede-ui v0.7.0 is out. `ganymede ui install` now defaults to 0.7.0,
with the SHA-256 of `ganymede-ui-0.7.0.zip`, the archive it downloads,
from the release's `SHA256SUMS` pinned beside it. The first push pinned
the `.tar.gz` hash by mistake; the `install_from_github` e2e test caught
it.

The "Unreleased in ganymede-ui." notes in docs/app.md, host-api.md,
in-app-kernel.md, ipados.md, privacy.md and roadmap.md are gone: the
in-app kernel registered with the app's server, the Notebook Access
sheet, `ganymede://run` parameters and the Mac update check all shipped
in 0.7.0. The text around two of them in app.md and ipados.md described
the old page kernel and now says what the apps do.

The review also found text that still described the apps before 0.7.0:
architecture.md's Mac and iPad setups, app.md's kernels table, the
where-kernels-run diagram (the iPad row showed Ganymede serving files
only and the kernel in the page) and its alt text. Those now say the
in-app kernel is one of the server's kernels. in-app-kernel.md says its
"The problem" section is the state before 0.7.0, and the roadmap lists
`ganymede://run` parameters as released.
