## 2026-11-20, docs after ganymede-ui 0.14.0 (#909)

ganymede-ui 0.14.0 ships the journal view and connected machines. The
apps' editing features (0.13.0) and the command line tool in the Mac app
(0.13.1) were already out, but their notes had stayed. The four
`**Unreleased in ganymede-ui.**` notes in `docs/app.md`, `docs/install.md`
and `docs/roadmap.md` are gone, and the text they marked now names the
release each feature shipped in. `docs/app.md` also says what versions
connected machines need.
