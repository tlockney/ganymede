## 2026-11-20, docs after ganymede-ui 0.14.0 (#909)

ganymede-ui 0.14.0 ships the journal view, connected machines, the apps'
editing features and the command line tool in the Mac app. The four
`**Unreleased in ganymede-ui.**` notes in `docs/app.md`, `docs/install.md`
and `docs/roadmap.md` are gone, and the text they marked now names the
release. `docs/app.md` also says what versions connected machines need.
