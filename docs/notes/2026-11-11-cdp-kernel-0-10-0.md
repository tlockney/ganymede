## 2026-11-11, cdp-kernel 0.10.0 (#670)

CI, the container image and the docs now use cdp-kernel 0.10.0. It
brings `jupyter.params` and `jupyter.result(name, value)` (cdp-kernel
#456), the kernel side of `execute -p`/`--results` and
`POST /api/notebooks/run`, and `jupyter.host()` (cdp-kernel #461), the
client for the host API. docs/getting-started.md names 0.10.0 instead of
"the release after 0.9.0".
