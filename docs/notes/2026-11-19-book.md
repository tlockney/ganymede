## 2026-11-19, the book on the site (#871)

The code architecture primer, written for Thomas as a Claude Doc, is now
served at `/book/` from `site/book/index.html`, and a short docs page at
the end of "How it works" (`docs/book.md`) explains it and links to it.

What to know:
- `site/book/index.html` is generated outside this repository: the
  maintainer's primer exported as Markdown, its diagrams rendered to
  inline SVG, in a one-chapter-at-a-time reader (routing by URL hash, no
  framework). The maintainer rebuilds it by hand; a small fix can go into
  the HTML directly, as docs/development.md says, but tell the maintainer
  so the next rebuild keeps it.
- Its fonts (Source Serif 4, Schibsted Grotesk, JetBrains Mono, OFL 1.1)
  are self-hosted in `site/book/fonts/`, so the page makes no requests to
  Google or anyone else; the rest of the site uses system fonts.
- It reads the docs' light/dark choice from `localStorage`, as the
  landing page does, and otherwise follows the system setting.
- The book is public now, so it must not point at private project
  material; one such reference was removed from the doc before
  publishing.
