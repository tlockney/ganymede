## 2026-11-19, the book on the site (#871)

The code architecture primer, written for Thomas as a Claude Doc, is now
served at `/book/` from `site/book/index.html`, and a short docs page at
the end of "How it works" (`docs/book.md`) explains it and links to it.

What to know:
- `site/book/index.html` is generated, not edited by hand: it is the
  Claude Doc exported as Markdown, its diagrams rendered to inline SVG,
  in a one-chapter-at-a-time reader (routing by URL hash, no framework).
  Rebuild it from the doc rather than patching the HTML.
- It reads the docs' light/dark choice from `localStorage`, as the
  landing page does, and otherwise follows the system setting.
- The book is public now, so it must not point at private project
  material; one such reference was removed from the doc before
  publishing.
