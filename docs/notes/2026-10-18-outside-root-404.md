## 2026-10-18, paths outside the contents root are 404 (#54)

The last item of [the #54 parity fixes](2026-10-18-server-parity-fixes.md).
`jupyter_server`'s `FileContentsManager._get_os_path` answers
`HTTPError(404, "<path> is outside root contents directory")` for a path
that resolves outside `root_dir`; we answered 403, because escapes shared
`Error::Forbidden` with read-only roots and writes to the root itself.

- `ganymede-contents` has a new `Error::OutsideRoot`, status 404. `..`
  components, absolute paths, backslashes and symlinks that resolve
  outside the root use it; the read-only and root-protection errors stay
  `Forbidden` (403), and a NUL byte stays 400, as in `jupyter_server`.
- The message still names the API path, never the OS path.

Learned: `jupyter_server` checks with `abspath`, so it follows a symlink
out of the root; we keep refusing those, only the status changed.

Left: `/api/spec.yaml` is still 404. Serving it means vendoring
`jupyter_server`'s OpenAPI file, and no client we target fetches it.
