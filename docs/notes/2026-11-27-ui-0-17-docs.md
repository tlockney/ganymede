## 2026-11-27, docs after ganymede-ui v0.17.0 (#964)

ganymede-ui v0.17.0 (published as v0.17.1) shipped the three app changes
that Ganymede's docs marked `Unreleased in ganymede-ui`: the browser's
first open (ganymede-ui#824), the browser header with Run Cell and the
status line (ganymede-ui#806) and DuckDB fetched on first use
(ganymede-ui#809). docs/app.md and docs/data-output.md now say these
plainly and the notes are gone. They name 0.17.1, the first release
with assets: v0.17.0's tag has no GitHub release, so
`ganymede ui install --version 0.17.0` finds no zip. `ganymede ui
install` still takes 0.16.0 by default (`DEFAULT_VERSION` in
crates/ganymede-cli/src/ui.rs), so the toolbar bullet keeps the older
toolbar too and scopes the new one to the browser; the apps' toolbars
differ and ganymede-ui's apps guide lists them. The privacy page's
note stays: ganymede-ui#846 isn't in a release yet.
