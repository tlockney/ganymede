## 2026-11-10, site intro by what Ganymede enables (#640)

The landing page opened with "The Jupyter server, without the Python."
and the README with "no Python runtime and no Python dependency". Both
describe Ganymede by what it lacks, which says little to someone who
never needed Python in the first place, and undersells the apps and the
agent work. The first screen, the README and the docs home now say what
it is for, with three ways in: TypeScript notebooks on cdp-kernel, agent
journals over `ganymede mcp`, and the Mac, iPad and iPhone apps.

The Python-free detail stays where it is useful: the "No Python runtime"
feature card, the Replacing Python page, and the README's status
section. The "Why" section now starts from the two uses that started the
project, TypeScript notebooks and an iPad app, rather than from Python.
The copy describes; it doesn't promote.
