## 2026-11-13, pin cdp-kernel 0.11.0 (#772)

cdp-kernel 0.11.0 ships `jupyter.table`, `jupyter.sql` and
`jupyter.chart` (#747). CI's e2e suite, the container image and the docs
that name the tested version move to it. `scripts/release-pins.sh` also
offered the ganymede-ui pin (0.8.0 to 0.10.1); that is left for the next
release, since it changes what `ganymede ui install` installs.
