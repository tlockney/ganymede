## 2026-11-09, diagrams for the rooms page (#594)

`docs/rooms.md` described rooms in prose only. It now has four SVG
diagrams in `docs/images/rooms/`, in the style of the architecture
diagrams: an overview of clients, the room and the file; the cell-by-cell
merge as a table of cases; running cells through the execute endpoint as
a sequence; and two servers on one notebook. The merge reads more easily
as a grid of "room + file → result" rows than as a flow, since each case
is independent. The SVGs were generated by a short script and checked in
light and dark in Chromium.

The execute diagram leaves out the unreleased `wait` reply, so the
diagram stays true for the latest release; the "Waiting for the cells"
subsection, which carries the Unreleased note, describes it.
