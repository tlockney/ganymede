## 2026-11-11, llms.txt and Markdown pages (#689)

The docs build writes llms.txt (the llmstxt.org format) and a copy of
each page's Markdown beside its HTML, so an agent reads `install.md`
instead of scraping `install`. `buildEnd` in config.mts calls llms.ts
with the sidebar's groups, so the index follows the sidebar's order and
picks up ganymede-ui's pages and the example pages when they were
fetched; a page that wasn't built is left out. Background and
contributors' groups go under "Optional:" headings, which llms.txt
readers may skip. Each entry carries the page's first sentence of prose,
taken after notes, code blocks and lists. The development log is left
out: its page is assembled by notes.ts, and notes.md alone is a stub.

The Pages workflow copies llms.txt to the site's root as well, and the
deploy smoke test fetches it and one Markdown page. No dependency: the
VitePress llms plugins would add one for what is about 90 lines here.
