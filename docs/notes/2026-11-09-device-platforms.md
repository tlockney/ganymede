## 2026-11-09, Device API is macOS and iOS only (#615)

The docs never said the `device` API exists only on Apple platforms.
`app.md` now says so, and the "Cell APIs" sidebar labels the page
"device (macOS and iOS)". The page itself comes from ganymede-device's
reference, which carries the same note (tlockney/ganymede-device#117),
as does ganymede-ui's guide (tlockney/ganymede-ui#431).
